# Sound effect sources

The sound files you downloaded go here (subfolders are fine). On GitHub, use
**Add file → Upload files**. Upload only the files you picked, not whole packs.

Then list them in [`../sfx.json`](../sfx.json) and run `tools/sfx/import.py`.
What to look for, and the licences: [SOUND_LIST.md](../SOUND_LIST.md). This
folder is public: Sonniss originals shouldn't go here unless the repo is private.
